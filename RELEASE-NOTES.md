# Balanced Stack Sizes 1.1.0+mc26.2-port.1

This is an unofficial community port of HB0P's archived Resizable Stacks / Balanced Stack Sizes project to Minecraft 26.2.

## Requirements

- Minecraft 26.2
- Java 25+
- Fabric Loader 0.19.3+
- Fabric API
- owo-lib 0.13.1+26.2

Install the mod and dependencies on both the server and clients.

The port was built successfully and tested on a dedicated Fabric 26.2 server. Existing playerdata containing a stack above its vanilla maximum loaded without item-stack decode errors. See `PORT-REPORT.md` for the exact source commit, implementation changes, and test record.

Release jar SHA-256: `FA79CC1247D988E7DEB0FE16E0B5E10804ACD8C23CB2D737CD5127DDE893E6CF`

The graphical positioning of four-digit item counts should be considered lightly tested. Please report client rendering problems through this repository's issue tracker.
